# FM-1 MIDI dongle

A small stick that plugs into the M-VAVE FM-1's USB-C port and gives it a **TRS MIDI OUT** and an
**isolated TRS MIDI IN**. The FM-1 is a USB MIDI device, so the dongle is a USB host built on the
WCH **CH32X035G8U6** (the cheapest WCH part with a full-speed USB host). It works with any FM-1 firmware
that sends MIDI over USB: Melodee, SLOOP, Felucca, Hortator, stock.

- `DESIGN.md`: the locked design, verified pins, open items, firmware plan, cost.
- `BOM.csv`: parts with LCSC numbers and a *Verified* column.
- `fm1-midi-dongle.kicad_sch` / `.kicad_pro`: KiCad 10 schematic (ERC clean). Generated by `tools/gen_sch.py`.
- `fm1_dongle.kicad_sym`: project symbol library (SY6280AAC).

Status (2026-10-17): schematic done; PCB layout and firmware not started. See the open items in `DESIGN.md`
before ordering anything (USB-C plug footprint and PCB thickness, jack footprint, optocoupler footprint).

## Hardware summary
- USB-C male plug to the FM-1 (host side, 56 kΩ Rp on CC), VBUS through an SY6280AAC load switch set to 1 A.
- USB-C female for 5 V in only (5.1 kΩ Rd on CC1/CC2), no data.
- MIDI OUT: 3.3 V TRS type A (10 Ω tip, 33 Ω ring).
- MIDI IN: H11L1SM optocoupler, 220 Ω, 1N4148 reverse diode, TRS type A.
- Programming: WCH-LinkE on a 3-pin SDI header (3V3 / PC18 DIO / GND).
